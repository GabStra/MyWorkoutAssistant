GVHMR-native fast post-processing profile:

1. Skip video_world_alignment for the gvhmr backend (gravity-aligned input; record skip reason in metadata); use the analytic ground (normal +Y) for ground metadata, keeping the fitted plane only as a sanity check.
2. Add `--skip-structural-refinement` / `structural_refinement_enabled` (default on = current behavior); fast profile skips it. Deterministic gates unchanged.
3. Fast bake flags: single baseline bake (`--rank-preview-variants=false --adaptive-preview-settings=false --select-preview-section=false`), minimal `--max-llm-review-items`, no final-output VLM in this profile.
4. `-FastProfile` switch on the runner scripts bundling: gvhmr backend + skip world alignment + skip structural refinement + single-baseline bake + no final VLM.
5. Validation batch (box jump, thruster, one support-drift failure, one known-good control): fast vs current profile, comparing gate outcomes, cleaned-motion geometry, and total time. Fallback: budget-capped refinement for failure classes.
6. Verify: py_compile, focused pytest, then the batch.

Never disabled: raw/baked/materialized deterministic gates, controlled-motion fit, physical validation.
