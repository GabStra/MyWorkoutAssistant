## Pending proposals are not approved decisions

The failed requirements review exposed rejected proposals as `proposedDecisions`.
They used the same `DECISION_n` representation as approved decisions. The model
then supplied a rejected proposal ID as `supersedes`. `propose_decisions` checked
only approved decisions and returned `settled_decision`, whose recovery advice
incorrectly instructed it to keep superseding a settled choice. The retained run
contains eight such errors.

`planning_decisions.py` now offers only active approved IDs in the tool's
supersession choices. A reference to a current rejected proposal is interpreted as
a draft correction and goes through ordinary authorization review. It does not
approve the rejected choice or bypass the guard on replacing an approved choice.
Unknown or stale IDs receive recovery advice that distinguishes a new proposal
from an approved decision. Source changes and newer requirements candidates
prevent reuse of a stale rejected proposal.

## Muscle credits do not establish physiological equivalence

The Clean and Push Press totals were not an arithmetic bug: the approved
convention assigns primary roles one credit and secondary roles half a credit.
The current library includes primary quads/glutes/delts and secondary hamstrings
for that definition. Both solver and audit consistently consumed those fields.

The missing evidence was the material dependence of each target on those
assignments. Individual contribution lists existed, but code did not show which
targets depended on a particular definition's credits. Review had to reconstruct
that arithmetic, despite code owning it.

`generation_audit.py` now computes `muscleCreditReliance` from the audited plan.
For each applicable target it reports the consequences of omitting one canonical
definition's assigned credits while holding everything else fixed. It preserves
direct versus weighted-indirect attribution, weekly frequency and session identity.
Unknown definition identity suppresses the affected identity-specific claim;
regional targets retain their separate evidence path. The same computed facts
reach the reviewer summary and code-rendered guidance.

In the retained plan, omitting Clean and Push Press's assigned credits leaves:

|---|---:|---:|---:|
| Quads | 15 | 8 | 7 |
| Hamstrings | 15.5 | 12 | 3 |
| Glutes | 18 | 11 | 4 |

This is a sensitivity diagnostic, not a new accounting convention, removal
recommendation, feasible replacement plan, or measurement of actual stimulus.
There is no new rejection gate or solver penalty. Missing exercise-specific
stimulus evidence cannot justify invented replacement coefficients.
