## Smallest safe representation

Keep reviewed evidence as optional data keyed to the exact exercise definition and matching equipment/accessory configuration. A generic projector may expose an optional `programmingDemands` map with only the fixed keys `unsupported_trunk`, `axial_loading`, and `eccentric_emphasis`; each emitted fact needs `present` and a source reference. Omit a key when evidence is missing or the variation is ambiguous. A confirmed external-support observation can imply `unsupported_trunk: present = false` only when that exact setup is verified; otherwise do not invert the support fact into a demand classification.

No current source reviewed here establishes reliable per-exercise axial-loading severity or eccentric-emphasis membership for this menu. Keep those fields absent/unknown. Do not infer demand groups from exercise names, muscle lists, categories, equipment alone, model qualification labels, or personal performance records. No runtime annotation, catalog migration, snapshot edit, or production code change was made for this audit.
